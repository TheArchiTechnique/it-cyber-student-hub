# IPv4 Subnetting Learning Lab

Learn subnetting from binary place values through a complete IPv4 calculation. Follow worked examples, enter each binary operation yourself, and keep a concise quick reference available while you practice.

- [Launch IPv4 Subnetting Learning Lab](https://thearchitechnique.github.io/it-cyber-student-hub/labs/networking/subnetting/app/)

## Learn, calculate, and check

The **Lesson** explains IPv4 octets, CIDR masks, binary AND, wildcard masks, broadcast addresses, usable ranges, and host capacity. Complete `/26` and `/23` examples show every intermediate calculation. A short introduction explains how VLSM uses different subnet sizes.

The **Workspace** provides five aligned binary rows and seven final-answer fields. Type an octet, paste an entire binary row, or edit individual bits. **Guided** mode checks one operation at a time; **Independent** mode checks the complete calculation. Feedback identifies the operation, octet, or bit to revisit. After an attempt, you can reveal the process without changing your answers.

The **Quick Reference** includes common masks, address counts, block sizes, and doubling/halving shortcuts. Switch sections without losing your workspace. Progress is saved in this browser when storage is available. Reset clears the current calculation after confirmation; New Example cycles through a fixed set of practice addresses. You can also enter your own IPv4 address and CIDR prefix or contiguous subnet mask.

No software installation is required. Use Tab to reach inputs and buttons, and arrow keys to move between the three section tabs. On a narrow screen, scroll inside the binary worksheet to keep matching bit positions aligned.
