# Windows Help Desk: Troubleshooting Multiple PCs

Investigate four managed Windows 11 workstations with simulated Command Prompts. Use diagnostic results to identify network, mapped-drive, Group Policy, and Windows integrity problems, then recommend appropriate corrective actions.

- [Launch Windows Help Desk: Troubleshooting Multiple PCs](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-2/windows-troubleshooting/app/)

Select a PC to read its support ticket and technical details. Type commands, inspect the output, and choose a root cause and remediation. Move between PCs freely; each retains its findings and command history. Submit all findings for up to 12 points and targeted feedback. Correct recommendations earn credit independently from diagnostic evidence.

The Lesson tab explains the commands and how to interpret their results. Contextual links open the [Windows Command-Line Reference](../../../../reference/windows-command-line.md) and [guided Windows Command-Line Lab](../../../../labs/it-support/windows-command-line/README.md) without leaving the activity.

Retry findings preserves your investigation and selections. Reset attempt restores the current tickets and clears progress. New Scenario changes computer names, addresses, resources, answer ordering, and fault variants. Progress is saved in this browser when storage is available. The terminal runs a restricted simulation entirely inside the page.
