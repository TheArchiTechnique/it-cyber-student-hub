# Home Network Configuration & Troubleshooting

Investigate a home office network, configure Windows and network devices, and verify the requested access.

- [Launch Home Network Configuration & Troubleshooting PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-2/home-network-configuration/app/)

    Work through DHCP, routing, DNS, wireless, and secure remote-access support tickets.

## What you will practice

Select devices in the topology to inspect adapter, router, wireless, and Windows Firewall settings. Use simulated `ipconfig`, `ping`, and `nslookup` commands, apply corrections, and run connection tests to confirm permitted access and blocked traffic.

Five ticket types include variants such as an exhausted DHCP pool, an incorrect subnet mask, an incompatible wireless client, and a firewall profile mismatch. Site addressing and the affected workstation vary between scenarios. The Lesson tab explains IPv4 configuration, Windows commands, wireless security, guest isolation, NAT, port forwarding, and VPN access.

Submit for partial credit and technical feedback. Diagnosis, corrective configuration, appropriate access, and fresh verification are scored separately. Continue editing to retry, Reset to repeat the same ticket, or select another ticket. Applied progress is saved in this browser.
