# Windows Startup Recovery

Recover two Windows computers using interactive startup screens, firmware settings, Windows Recovery Environment, and a simulated Command Prompt. Investigate a UEFI/GPT boot-configuration failure and a legacy BIOS/MBR boot-loading failure.

- [Launch Windows Startup Recovery](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-2/windows-startup-recovery/app/)

Navigate through Choose an option, Troubleshoot, and Advanced options. Inspect disk detection, boot configuration, Startup Repair reports, and command output. Type recovery commands, respond to prompts, apply repairs, and restart to verify normal Windows startup. Each computer retains its own investigation and repair state.

Submit your attempt for up to 12 points with targeted feedback. Retry recovery continues your current investigation. Reset attempt clears both computers and restores their original failures. Progress and optional service notes are saved in this browser when storage is available. All commands run inside a restricted simulation.

The Lesson tab explains the Windows boot process, BIOS/MBR and UEFI/GPT differences, BCD, the four BOOTREC operations, BCDBoot, diagnostic interpretation, and verification. The [Windows Command-Line Reference](../../../../reference/windows-command-line.md) provides additional command examples.
