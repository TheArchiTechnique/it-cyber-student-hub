    Understand the network choices

    Follow the connection from the internet to the router, then to each network and device. Match the configuration to the customer's requirements.

    1 · Private, public, and APIPA

    Private IPv4 addresses are for internal networks: 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, and 192.168.0.0–192.168.255.255. Two separate homes can use the same private range.

    Public IPv4 addresses can be globally routed when assigned and routed by a provider. An address outside the private ranges is not automatically public: loopback, multicast, and other reserved ranges also exist.

    APIPA uses 169.254.0.0/16 for link-local addressing, often when Windows cannot obtain a DHCP lease. It is not an RFC 1918 range and routers do not forward this traffic. 127.0.0.0/8 is loopback, used to reach the local host.

    The WAN addresses in these diagrams use documentation ranges: 192.0.2.0/24, 198.51.100.0/24, and 203.0.113.0/24. They stand in for public ISP addresses in examples and are not publicly routed.

    2 · Host addresses and gateways

    An IP address and subnet mask identify a host and its network. In 192.168.72.0/24, /24 means mask 255.255.255.0. Usable host addresses are .1 through .254; .0 is the network address and .255 is the broadcast address.

    Give each device a unique host address in the required subnet. Avoid addresses already assigned to another device. A valid private address in a different subnet still does not satisfy a same-LAN requirement.

    The default gateway is the router interface on the client's own network. If that interface is 192.168.72.254, clients use .254 to reach other networks. The gateway need not end in .1, and it is not the router's WAN address.

    3 · LAN and WAN

    A LAN connects local devices, such as workstations and a shared printer. A switch connects wired devices in the LAN; an access point connects wireless clients.

    The WAN connection links the router to a provider's wider network. A typical home router combines a router, switch, access point, firewall, and address translation.

    The router has different addresses on its different network interfaces. Connect a shared internal printer to the LAN, and the ISP uplink to the WAN port. Wi-Fi can belong to the same LAN or to a separate guest network.

    4 · Services, ports, and transports

    A service's port identifies the listener. TCP provides an ordered byte stream with delivery mechanisms. UDP carries independent datagrams without TCP's delivery or ordering guarantees. Applications can add their own reliability or security to UDP.

    HTTP/3 uses QUIC over UDP, commonly on port 443. Read the specified transport. A configured application listener can use a different port; a port number by itself does not identify a service with certainty.

    5 · NAT and port forwarding

    Network address translation (NAT) changes IP addresses as traffic crosses the router. PAT also translates ports so multiple private devices can share one public IPv4 address. The router tracks translations to deliver replies to the initiating host.

    Port forwarding creates a destination mapping for an inbound listener. For example, a configured TCP listener on WAN port 8443 might forward to an internal server at 192.168.72.40, TCP port 443.

    Match the external port, transport, destination address, and destination port. TCP and UDP mappings are distinct. The firewall must permit the intended traffic, and the destination must retain its address. Opening every port or forwarding to the wrong host does not meet a single-service request.

    6 · Screened subnet / DMZ

    A screened subnet, also called a DMZ, is a separate network for services that external users need to reach. A firewall controls traffic between the WAN, this network, and the internal LAN.

    A public website can use a private address in the DMZ behind an inbound NAT mapping. Staff workstations, printers, and internal backups can remain in the LAN. Placement alone does not provide protection: the firewall must enforce the boundaries.

    Permit the required public service and restrict new DMZ-to-LAN sessions. A stateful firewall can distinguish replies to allowed sessions from new sessions. A consumer router's DMZ host setting, which forwards broad inbound traffic to one device, is different from a separately filtered subnet.

    7 · Wireless security and guests

    WPA3-Personal offers modern personal Wi-Fi security when both the access point and clients support it. WPA2-Personal with AES supports many older clients. Match the strongest suitable mode to the actual client requirement.

    Use a strong passphrase. WEP and WPA with TKIP are outdated. A personal network does not require the authentication server normally used by Enterprise modes.

    A separate guest SSID and subnet can give visitors internet access. Enable guest-to-LAN isolation in the router; a different network name alone does not prevent LAN access. Guest client isolation controls communication between guests and is a separate setting.

    8 · Read the diagram

    Start at the internet node. Follow the WAN link to the router, then identify each LAN, screened subnet, or guest segment. Solid lines represent wired links; dashed lines represent wireless links.

    Read the supplied network ranges, interface addresses, and device roles before choosing a host address. For an external service, follow its path from the WAN listener through the router to the correct destination.

    Check four things: where the device belongs, which address fits its subnet, which service and transport are needed, and which access the customer permits. Each choice is scored independently.
