# Network Configuration Concepts

Configure three connected network diagrams covering IPv4 addresses, LAN and screened-subnet placement, services and ports, wireless security, NAT, and port forwarding.

- [Launch Network Configuration Concepts](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-2/network-configuration-concepts/app/)

Choose Home Office, Small Business, or Residential Network with Hosted Service. Each scenario has seven or eight configuration choices. Submit for partial-credit scoring and a technical explanation of every decision.

Use the Lesson tab to review the concepts. Retry selections keeps your choices for adjustment. Reset scenario clears the current scenario and reshuffles its choices. Switching scenarios preserves your work until the page is reloaded.
