# Network Cabling & Physical Installation PBQ

Install a building network, identify media and connectors, interpret termination tests, select tools, and resolve physical connectivity faults.

- [Launch Network Cabling & Physical Installation PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/network-plus/physical-cabling-installation/app/)

    Complete the building work order or open the Lesson tab to learn structured cabling with annotated diagrams and real equipment photographs.

## What you will practice

Assign MDF and IDF roles, inspect all three racks, distinguish passive panels from active switches, and select media from documented speed, distance, interface, and environmental requirements. Connect work areas to distribution equipment, choose compatible backbone fiber, distinguish twinax DAC from horizontal copper, and apply a stated plenum-jacket requirement.

Inspect real photographs of cable construction, eight connector families, and pluggable modules. Interpret simulated termination and field-test records, select cable testers, toners, or a visual fault locator, and resolve four physical faults. The Lesson tab includes oriented T568A/T568B diagrams, compatibility comparisons, and tool limitations.

Drag labels and cables, select an item and its target, or use the dropdown alternatives. Each of the 37 decisions earns credit independently. Submit to see the correct choices and technical explanations, continue editing to improve your design, or reset for a new attempt. Progress is saved in the current browser when storage is available.
