# Power Protection & UPS

Inspect a small-office work order, connect power-protection equipment, and test what happens when utility power fails.

- [Launch Power Protection & UPS PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/power-protection/app/)

    Practice workstation shutdown, network continuity, UPS capacity, and backup-failure troubleshooting.

## What you will practice

Four scenario types cover protecting a workstation, keeping a network service path powered, managing load and runtime, and diagnosing an existing backup failure. Inspect equipment ratings and requirements, then assign a power source using each device's selection control. The network cases include AC-powered and PoE-powered endpoints.

Test Power Failure shows the consequences of your actual connections, including lost equipment power, overload, runtime limits, and service availability. It does not submit your answer. Revise and retest, then Submit solution for requirement-based scoring and explanations. Troubleshooting also checks your diagnosis and applied correction.

The integrated Lesson tab covers power disturbances, protection equipment, backup priorities, watts and VA, runtime, troubleshooting, and safe connections. Short knowledge checks provide explanations after each answer.

Reset restores the same work order and original fault. New Scenario selects a different scenario type. This browser saves the active case, equipment connections, UPS selection, battery maintenance, diagnosis, and results.

Equipment ratings and conservative runtime tables are supplied scenario data. Actual installations require the manufacturer's ratings, runtime information, compatibility guidance, and maintenance instructions. The network test assumes external providers remain available during the local interruption.
