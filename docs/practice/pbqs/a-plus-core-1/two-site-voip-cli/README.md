# Two-Site VoIP Troubleshooting

Compare two office networks, investigate call-quality symptoms with simulated terminals, and apply a repair supported by your evidence.

- [Launch Two-Site VoIP Troubleshooting PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/two-site-voip-cli/app/)

    Diagnose jitter, latency, packet loss, or insufficient bandwidth, then configure and retest a repair.

## What you will practice

Use the functioning office as a baseline. Each terminal supports a restricted set of diagnostic commands; type `help` to see them. Choose the primary issue, likely cause, and corrective action, then apply a repair profile at the affected site. The Lesson tab explains the evidence and where real call-quality measurements come from.

The terminals are JavaScript simulations. `voipstat` is an activity-only command, not a standard Windows command.

Command choice and order are not scored. Submit for targeted feedback and continue editing to try again. Reset restores the same problem. New Scenario selects a different fault and may change the affected site. The current scenario, terminal history, answers, and applied configuration are saved in your browser.
