# IP Configuration Troubleshooting

Compare two PCs, investigate IPv4 configuration with simulated command prompts, and apply a fix supported by your evidence.

- [Launch IP Configuration Troubleshooting PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/ip-configuration-troubleshooting/app/)

    Diagnose address conflicts, DHCP failures, and incorrect IP, mask, gateway, or DNS settings.

## What you will practice

Use `ipconfig`, `ipconfig /all`, and `ping` to inspect each PC independently. Type `help` for available commands and targets. Select the problem and corrective action, then apply settings in the network configuration panel and retest. The Lesson tab explains the evidence and comparison method.

The terminals are restricted JavaScript simulations. Commands and command order are not scored. Diagnosis, corrective action, and applied configuration earn separate credit. Submit for feedback and continue editing to retry.

Reset restores the same scenario. New Scenario selects a different fault and may change the affected PC. Your scenario, terminal history, answers, and settings are saved in this browser.
