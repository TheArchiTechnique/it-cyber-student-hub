# Printer Troubleshooting

Inspect printer components and symptoms, then diagnose common laser and inkjet printer problems.

- [Launch Printer Troubleshooting PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/printer-troubleshooting/app/)

    Open the interactive browser activity.

## What you will practice

Recognize common laser and inkjet printer components, connect print-quality and hardware symptoms to likely causes, choose practical troubleshooting actions from scenario evidence, and inspect device details before making a diagnosis.
