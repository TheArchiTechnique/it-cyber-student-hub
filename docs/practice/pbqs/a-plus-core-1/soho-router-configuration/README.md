# SOHO Router Configuration

Configure a small office/home office router from a work order. Practice LAN addressing, DHCP, employee Wi-Fi, guest Wi-Fi, wireless bands, channels, and security settings.

[Launch SOHO Router Configuration PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/soho-router-configuration/app/)

## What you will practice

- Configure a router LAN address, subnet mask, DHCP pool, gateway, and DNS settings.
- Choose wireless bands and security settings for different client requirements.
- Configure a guest network and select an appropriate 2.4 GHz channel.
- Interpret a simple office network diagram and work order.
