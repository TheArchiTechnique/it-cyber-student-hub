# TCP/IP Packet Walk

Follow data from a client to a network service and identify what happens as the traffic moves through the network.

- [Launch TCP/IP Packet Walk](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/tcp-ip-packet-walk/app/)

    Open the interactive browser activity.

## What you will practice

Follow a packet through common network devices, recognize encapsulation and decapsulation as data moves through the stack, distinguish local forwarding from routed communication, and connect network-device roles to the traffic path.
