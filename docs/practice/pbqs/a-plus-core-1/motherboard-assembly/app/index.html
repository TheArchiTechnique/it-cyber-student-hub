Board reference

This is a simplified teaching board, not a specific retail model. Use these specifications as the system’s manual excerpt.

CPU & memoryLGA desktop CPU; four DDR5 desktop DIMM slots. Channel A: A1/A2. Channel B: B1/B2. With two modules, the manufacturer specifies A2 and B2.
ExpansionUse the primary PCIe x16 slot for graphics and the PCIe x1 slot for the network card. The supplied graphics card also requires its single 8-pin auxiliary power socket to be connected.
StorageM-key PCIe/NVMe M.2 2280 socket and SATA data ports. Connect both ends of the SATA data cable and the drive’s power connector in the detail view.
Power24-pin ATX main power and one 8-pin CPU power socket.
Cooling & USB4-pin CPU_FAN header and 19-pin internal USB 3.x header for the case’s front USB ports.
Case controlsF_PANEL header for the case power/reset switches and indicator LEDs. Connect the lead set to the header area; individual pins are not graded.

Memory installation: place each 8 GB module into its own slot. The two modules are interchangeable. Choose the manufacturer’s recommended two-module configuration.
