# Motherboard Assembly

Install desktop components, configure a matched memory pair, and connect the motherboard, graphics card, and SATA drive.

- [Launch Motherboard Assembly PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/motherboard-assembly/app/)

    Open the lesson and interactive assembly activity.

## What you will practice

Recognize desktop components and headers, follow the board reference for dual-channel memory placement, distinguish PSU connectors, install the CMOS/RTC battery, and connect SATA data and power. Drag parts or select a part and then its target. Check your build for explanations, then continue editing.
