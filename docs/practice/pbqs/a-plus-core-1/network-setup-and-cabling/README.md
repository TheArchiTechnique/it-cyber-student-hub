# Network Setup & Cabling

Build a small network by selecting appropriate devices, media, connectors, and cabling choices for the scenario.

[Launch Network Setup & Cabling PBQ](https://thearchitechnique.github.io/it-cyber-student-hub/practice/pbqs/a-plus-core-1/network-setup-and-cabling/app/)

## What you will practice

- Match network devices to their roles.
- Choose appropriate copper, fiber, and other connection types.
- Apply Ethernet termination and cabling concepts.
- Make practical connection choices from scenario requirements.
