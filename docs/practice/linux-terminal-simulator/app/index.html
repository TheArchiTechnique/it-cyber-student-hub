    Nano help
    Type to insert text. Enter creates a line; Backspace and Delete remove text. Use arrows, Home, and End to move the cursor. Select, copy, and paste using your browser’s normal controls.
    Ctrl+O opens Write Out. Confirm the filename with Enter. Ctrl+X exits; choose Y to save, N to discard, or Ctrl+C to cancel when asked. Ctrl+G opens this help. Use the buttons below the editor on touch devices.
    Saved nonempty text ends with a newline. Files and directory permissions apply when saving. Changes stay in the buffer if saving fails.

    Supported practice and shell syntax
    
    Try mkdir -p ~/Practice/Reports, then cd ~/Practice/Reports. Open nano workstation-report.txt, write a few lines, press Ctrl+O and Enter to save, then Ctrl+X to exit. Verify with cat workstation-report.txt. The editor also has touch controls.
    
    
    Use absolute or relative paths, ~, $HOME, ., .., and quoted names with spaces. > overwrites and >> appends. Filenames are case-sensitive. touch preserves existing content. Long listings show simulated permissions, ownership, text sizes in bytes, and UTC modification times; directory sizes are modeled as zero.
    
    
    Available commands: pwd, ls, cd, cat, whoami, mkdir, touch, echo, clear, help, man. File tools: nano, cp, mv, rm, grep, find, chmod, chown. Each manual lists supported syntax. System tools: sudo, su, exit, ps, top, du, df, mount, umount, fsck. Network tools: ip, ping, dig, traceroute, curl. Package tools: apt in Mint and dnf in the separately saved Fedora practice profile.
    
    
    Administration uses a fictional password-free training policy. sudo whoami runs one command as root; sudo su - opens a root shell and exit returns to your previous account. Direct root login is locked. Never enter real passwords here. top opens a simulated process snapshot; press Q to return.
    
    
    du counts UTF-8 text rounded up to 1 KiB per file; empty files and directories use zero modeled data blocks. df includes those blocks plus a fixed fictional system-image allocation. Mount /dev/sdb1 at /mnt/training-disk with sudo to inspect the secondary volume. Its Reports directory is writable by student. Unmount before using the read-only fsck -n check. Repairs are not simulated.
    
    
    Inspect this fictional network with ip addr and ip route. Try ping -c 4 files.training.example, dig portal.training.example, and curl -I http://files.training.example. Downloads such as curl -o report.html http://files.training.example/report create real files inside this simulated workstation. Timings and services are modeled; these commands send no network requests.
    
    
    Package catalogs and versions are fictional. apt show nano and apt search traceroute inspect Mint packages. Use sudo for package changes. Removing optional curl, traceroute, or DNS utilities disables their commands until reinstalled. Nano and other foundational tools are protected. Select Fedora DNF practice to use dnf info nano; switching profiles preserves Mint work.
    
    
    Enter one command at a time. Pipes, shell wildcard expansion, command chains, substitutions, shell scripts, and interactive standard input are not implemented. No network requests or host commands run from this terminal.
    
    
    Organize a saved report with cp workstation-report.txt backup.txt, mv backup.txt resolved-ticket.txt, and chmod 600 resolved-ticket.txt. Search its contents using grep -n "Status" workstation-report.txt, or locate reports using find ~/Practice -name "*.txt". Keep find patterns quoted. For searchable sample events, try grep -in error /var/log/application.log.
