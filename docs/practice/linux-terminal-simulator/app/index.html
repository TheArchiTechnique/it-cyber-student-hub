Linux Terminal Simulator

Practice on a simulated Linux Mint workstation in your browser. Commands change this workstation’s files, not your computer’s operating system. Your files and command history are saved in this browser when storage is available.

Start with help, explore with ls, or open a short manual with man ls. Use the Linux Command-Line Reference for broader explanations.

student-linux

Enter runs a command. Up/Down recalls commands. Tab completes simple command names and paths. Ctrl+C cancels input. The output area can be focused and scrolled to review or copy text.

Supported practice and shell syntax

Try mkdir -p ~/Practice/Reports, then cd ~/Practice/Reports. Write echo "Linux workstation report" > report.txt and verify it with cat report.txt. Commands act on the same files throughout your session.

Use absolute or relative paths, ~, $HOME, ., .., and quoted names with spaces. > overwrites and >> appends. Filenames are case-sensitive. touch preserves existing content. Long listings show simulated permissions, ownership, text sizes in bytes, and UTC modification times; directory sizes are modeled as zero.

Available commands: pwd, ls, cd, cat, whoami, mkdir, touch, echo, clear, help, man. Each manual lists supported options. Nano and additional commands are not available yet. Guided assignments will be added later.

Enter one command at a time. Pipes, wildcards, command chains, substitutions, shell scripts, and interactive standard input are not implemented. No network requests or host commands run from this terminal.
