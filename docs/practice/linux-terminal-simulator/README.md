# Linux Terminal Simulator

Practice Linux commands directly in your browser. No virtual machine, Linux installation, or account is required. Use this Linux terminal for guided workstation exercises and command-line practice.

- [Launch Linux Terminal Simulator](https://thearchitechnique.github.io/it-cyber-student-hub/practice/linux-terminal-simulator/app/)

## Command-line practice

**Guided Practice** walks you through preparing and troubleshooting a workstation. Build a report with Nano, organize files, inspect permissions and resources, use training storage, manage packages, and investigate networking. **Free Practice** lets you explore the same workstation at your own pace. Switching modes keeps your files and progress.

Use `nano` to create, edit, and save virtual files. Enter `man COMMAND` for concise syntax and command help, or `help` to explore the available tools. Keep the [Linux Command-Line Reference](../../reference/linux-commands.md) available for explanations and examples.

Workstation files, command history, and guided progress are saved locally in this browser when storage is available. Return using the same browser to resume. **Linux Mint** and **Fedora DNF practice** keep separate environments, so switching profiles preserves each workstation's work.

For practice on a real virtual machine, start with [VirtualBox: Installing Linux Mint](../../labs/it-support/virtualbox-linux-mint/README.md), then continue to [Linux Mint Workstation Setup and Troubleshooting](../../labs/it-support/linux-mint-command-line/README.md). Those VM labs are a separate learning path; they are not prerequisites for this simulator.
