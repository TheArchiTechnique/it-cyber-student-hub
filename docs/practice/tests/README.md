# Practice Tests

Build a focused practice test by selecting domains, individual objectives, and the number of questions. Questions and answer choices are shuffled for each new test.

- [Launch A+ Core 2 Practice Test](app/index.html)

    Practice with 24 original questions for CompTIA A+ Core 2 (220-1202), covering all four domains. Select only the objectives you want to review. Objectives without questions are shown as unavailable.

Choose whether to see correct answers and detailed explanations. Explanations identify the correct answer, so they require correct-answer feedback. You can receive feedback after completing the test or after explicitly checking each answer. Once feedback is revealed, that response is locked.

Single-answer questions have one correct choice. Multiple-response questions state how many choices to select and require the entire correct set for credit. Unanswered questions receive no credit. Results show a practice percentage and a breakdown of the questions assessed by domain and objective.

Your unfinished test is saved locally in the same browser when browser storage is available. Refreshing restores its questions, answer order, selections, flags, and current position. Starting a new test discards the previous session. No account, subscription, or AI service is required.

This initial bank supports focused practice and does not cover every objective. Small samples cannot establish mastery. The questions are independently authored, and practice percentages are not CompTIA scaled scores.

For quick knowledge reinforcement, use the existing [Practice Questions and Kahoot reviews](../questions/README.md). For interactive performance-based tasks, visit [PBQ Practice](../pbqs/README.md).
