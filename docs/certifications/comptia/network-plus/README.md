## Published PBQ Practice

### Direct Certification Practice

- [Network Cabling & Physical Installation PBQ](../../../practice/pbqs/network-plus/physical-cabling-installation/README.md)

    Install a building network, identify media and connectors, interpret termination tests, select tools, and resolve physical connectivity faults.

### Foundational Practice

Related activities that build supporting skills for this certification.

- [IP Configuration Troubleshooting](../../../practice/pbqs/a-plus-core-1/ip-configuration-troubleshooting/README.md)

    Compare two PCs, investigate IPv4 configuration with simulated command prompts, and apply a fix supported by your evidence.

- [Network Setup & Cabling](../../../practice/pbqs/a-plus-core-1/network-setup-and-cabling/README.md)

    Build a small network by selecting appropriate devices, media, connectors, and cabling choices for the scenario.

- [Ports & Protocols](../../../practice/pbqs/a-plus-core-1/ports-and-protocols/README.md)

    Choose services and ports for support tickets, classify transport behavior, match protocols to their purpose, and diagnose multi-part networking problems. Practice covers the A+ Core 1 220-1201 port set.

- [SOHO Physical Installation](../../../practice/pbqs/a-plus-core-1/soho-physical-installation/README.md)

    Build a physical Internet connection from the service outlet to the local network. Recognize equipment and connector shapes, place the equipment, connect each cable to two ports, and practice current Core 1 network tools through job matching and tool-function questions.

- [SOHO Router Configuration](../../../practice/pbqs/a-plus-core-1/soho-router-configuration/README.md)

    Configure a small office/home office router from a work order. Practice LAN addressing, DHCP, employee Wi-Fi, guest Wi-Fi, wireless bands, channels, and security settings.

- [TCP/IP Packet Walk](../../../practice/pbqs/a-plus-core-1/tcp-ip-packet-walk/README.md)

    Follow data from a client to a network service and identify what happens as the traffic moves through the network.

- [Two-Site VoIP Troubleshooting](../../../practice/pbqs/a-plus-core-1/two-site-voip-cli/README.md)

    Compare two office networks, investigate call-quality symptoms with simulated terminals, and apply a repair supported by your evidence.

- [Wireless Coverage](../../../practice/pbqs/a-plus-core-1/wireless-coverage/README.md)

    Troubleshoot a weak, intermittent Wi-Fi connection in a 3,000-square-foot office. Inspect the floor plan and reposition available equipment to improve service across the workspace.

## Published Labs

- [IPv4 Subnetting Learning Lab](../../../labs/networking/subnetting/README.md)

    Learn binary subnet calculations, identify network and broadcast addresses, find host ranges, and practice with randomized questions and calculation feedback. No installation required.

- [Getting Started: Download and Install Cisco Packet Tracer](../../../labs/networking/packet-tracer-setup/README.md)

    Set up the free network simulator and learn the controls used in the Network+ networking labs.

- [Lab 1 — Basic Network Configuration](../../../labs/networking/basic-network-configuration/README.md)

    Build a small LAN, assign static IPv4 addresses, and verify PC and gateway communication.

- [Lab 2 — VLAN Configuration](../../../labs/networking/vlan-configuration/README.md)

    Continue Lab 1 with Sales and HR VLANs, an 802.1Q trunk, and router-on-a-stick inter-VLAN routing.

- [Lab 3 — Static Routing](../../../labs/networking/static-routing/README.md)

    Add a second router and static return routes to the VLAN networks over a /30 transit link.

- [Lab 4 — DHCP Configuration](../../../labs/networking/dhcp-configuration/README.md)

    Configure Router0 to assign IPv4 settings to Sales and HR clients using separate DHCP pools.

- [Lab 5 — Centralized DHCP and DNS Services](../../../labs/networking/centralized-dhcp-dns/README.md)

    Move DHCP to Server0 in Services VLAN 30, relay client requests, and configure internal DNS records.

- [Lab 6 — ACL Traffic Control](../../../labs/networking/acl-traffic-control/README.md)

    Control routed Sales/HR traffic with named extended ACLs while preserving access to shared services.

- [OSI & TCP/IP Models — PDU Encapsulation and Decapsulation](../../../labs/networking/osi-pdu-tracing/README.md)

    Independent N10-009 lab: build a small two-subnet topology and follow ARP, ICMP, TCP, and HTTP PDUs through endpoints, switches, and a router. No earlier labs required.
